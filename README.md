## ✨ Características clave 

* **🎨 Reconocimiento de gestos de la interfaz de usuario:** 
  Lienzo flotante interactivo (superposición) que captura trazos en tiempo real sobre cualquier aplicación o juego sin interrumpir el flujo del sistema. 

* **⚡ Automatización Root Integrada (Macros):** 
  * Mapeo de dibujos simples (letras, formas, curvas) para activar secuencias multitarea complejas. 
  * Inyección precisa de coordenadas (`input tap`, `input swipe`) y comandos del sistema (`am start`, `am force-stop`).  
  * Capacidad para automatizar flujos de trabajo completos en aplicaciones de terceros (por ejemplo, abrir chats específicos, enviar contenido y repetir interacciones táctiles). 

* **📈 Rendimiento Optimizado:** 
  Algoritmo ligero de reconocimiento de patrones diseñado para minimizar el uso de CPU y el impacto de la batería durante la escucha activa. 

* **🛡️ Integración Segura de Superusuario:** 
  Totalmente compatible con binarios root modernos a través de Magisk o KernelSU para una ejecución fluida del comando `su`.
